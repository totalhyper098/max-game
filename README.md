# MAXGAME Foundation

Clean starting structure for MAXGAME.

- index.html — Home UI
- css/styles.css — styling
- js/app.js — interactions and carousel
- data/games.js — game and reward configuration

Planned modules: Local multiplayer, AI modes, online multiplayer, XI rewards, tasks, skins, profiles and leaderboards.

Game configuration is separated from the UI so future content can be expanded without rewriting the whole home page.
